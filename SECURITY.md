# Security Policy

## Supported versions

The latest release is supported. We do not ship separate security fixes for
earlier releases; fixes are delivered in the next release. The Kit is copied
into a project rather than installed as a dependency, so taking a fix means
copying the updated files from that release.

## Reporting a vulnerability

**Do not report security issues through public GitHub issues, pull requests,
or discussions.** GitHub Issues are disabled in this repository, so the
private channel below is the only intake path.

| Channel | Address |
| --- | --- |
| Private vulnerability report | <cs-platform@com2us.com> |

Including the following helps us confirm a report quickly:

- Affected screen or file, and the Kit version (`versions.yaml`)
- Unity version and target platform
- Reproduction steps and the minimum environment needed
- Expected impact
- Any mitigation you are aware of

## What happens next

Reports are handled under Com2uS Platform's security incident response
process. We acknowledge receipt and share progress through the intake channel
you used. Nothing about a report appears in this repository until a fix is
published.

We do not commit to response or resolution timelines.
